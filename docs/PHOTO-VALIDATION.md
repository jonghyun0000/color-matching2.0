# 실제 의류 사진 30장 검증 — 2026-09-12

## 결론

30장 모두 분석이 끝났지만, 카탈로그 색 라벨과의 일치는 **첫 번째 색 12/30(40.0%), 화면에 표시하는 세 후보 안에서는 19/30(63.3%)**였습니다.

이는 **작은 상품사진 세트에서의 색 계열 라벨 일치율**입니다. 색의 물리적 정확도, 실제 촬영 환경 정확도, 코디 추천 만족도 또는 전체 사용자 성능으로 해석하면 안 됩니다. 실행 오류가 없다는 사실도 색 인식 품질을 보장하지 않습니다.

다음 기능을 늘리기 전에 **색 이름 매핑을 먼저 수정하고, 이후 옷 영역 선택을 도입**하는 순서를 권합니다. 이 검증에서는 앱 알고리즘을 변경하지 않았습니다.

## 자료와 선정 방법

- 출처: [Fashion Product Images Small / ashraq](https://huggingface.co/datasets/ashraq/fashion-product-images-small). 데이터 카드가 연결한 원출처는 [Param Aggarwal의 Kaggle 데이터셋](https://www.kaggle.com/datasets/paramaggarwal/fashion-product-images-small)입니다.
- `train`을 행 순서대로 탐색해 `Apparel` 중 `Topwear`/`Bottomwear`만 선정했습니다.
- Black, White, Blue, Navy Blue, Grey, Red, Green, Pink, Yellow, Beige 각각 **처음 3장**. 결과를 보기 전에 선정 규칙과 30장을 고정했습니다. 마지막 선정 행은 452입니다.
- 모든 이미지는 **60×80 픽셀**입니다. 주로 흰 배경의 착용 또는 단독 상품사진이며, 체크·줄무늬·프린트도 포함되어 있습니다.
- 저해상도 사진을 앱과 동일하게 중앙 샘플링하고 Canvas로 확대합니다. 이 과정의 보간색은 원본 직물의 정확한 색이 아닐 수 있습니다.
- 이미지는 로컬 `.validation/`에만 보관합니다. 재배포 허가가 명확하지 않아 저장소에는 원본 사진을 올리지 않았습니다.
- [결과 JSON](validation/results-2026-09-12.json)에 상품 ID, 행, 색 라벨, 이미지 SHA-256, 출력 HEX와 이름을 남겼습니다.

## 확인한 문제와 개선 우선순위

### 1. 거의 무채색인 픽셀에 유채색 이름이 붙음 — 우선 수정

- 상품 42419: 거의 흰색인 `#FBFDFD`를 **페이디드 데님**으로 매핑합니다.
- 상품 13089: 밝은 회색 `#DCDDDA`를 **세이지 그린**으로 매핑합니다.
- `#FFFFFF`는 정상적으로 흰색이지만 아주 작은 RGB 차이만 생겨도 이름이 바뀝니다.
- 원인 근거: `hslDistance`는 Hue·Saturation·Lightness 차이를 그대로 결합합니다. 색도가 낮거나 극도로 밝은 영역에서도 Hue 차이가 크게 작용합니다. `#FBFDFD`의 HSL은 H=180, S=33, L=99로 계산되어, 시각적으로 거의 흰색이어도 사전 매핑이 흔들립니다.
- 필요한 수정: 저색도/극단 명도 처리와 색 거리 정의 검토. 옷 영역을 크롭해도 이 문제는 남으므로 먼저 처리해야 합니다.

### 2. 바지보다 흰 배경 또는 피부색이 1순위 — 영역 선택 필요

- 검정 바지 21379와 18005: 1순위는 각각 `#FDFCFC`, `#FCFBF9`로 흰 배경에 가깝습니다.
- 파란 반바지 54924: 1순위 `#E3BC9F`는 사진의 피부색과 비슷하고, 옷 색은 2순위입니다.
- 베이지 반바지 56822도 흰색이 1순위입니다.
- 원인 추정: 중앙 정사각형 샘플만으로는 전신/하의 사진에서 옷과 배경·피부를 분리하지 못합니다. 밝음·무채색·어두움에 대한 일괄 가중치는 흰옷과 검은옷 자체도 낮게 평가할 수 있습니다.
- 필요한 수정: 사용자가 옷 영역을 지정하고 확인하는 흐름. 전체 이미지와 선택 영역을 같은 사진으로 비교해야 합니다.

### 3. 추출색이 그럴듯해도 이름 사전이 부정확함

- 빨간 상의 18237의 `#F95F66` → **비비드 오렌지**. 해당 사전 항목은 yellow 계열이라 라벨 비교도 불일치입니다.
- 노란 상의 10065·6287은 yellow 계열 일치로 계산되지만 이름은 **비비드 오렌지**입니다.
- 따라서 **계열 일치와 한국어 색 이름 품질을 별도로 평가**해야 합니다. 이 표는 이름이 자연스럽다는 것을 검증하지 않습니다.

### 4. 상품 라벨은 픽셀 정답이 아님

- 9660은 Pink 라벨이지만 공개 사진에는 어두운 셔츠가 보입니다. 이는 라벨/표시 이미지 정합성 문제로 보이며, 곧바로 추출 알고리즘 실패라고 단정할 수 없습니다.
- 9452는 Red 라벨이지만 흰색과 붉은색 줄무늬가 저해상도에서 섞여 회분홍으로 보입니다.
- 5891은 Black 라벨의 굵은 흰·검정 줄무늬라 하나의 대표색만 정답으로 두기 어렵습니다.
- 20099는 Green 라벨이지만 사진에서는 황록색에 가깝습니다. 조명과 라벨 범주의 영향을 분리하지 못했습니다.

## 아직 검증하지 못한 것

- 사용자가 휴대전화로 찍은 고해상도 사진 20–30장
- 실내 노란 조명, 역광, 어두운 방, 복잡한 생활 배경
- 동일한 옷을 다른 조명에서 찍었을 때의 일관성
- 의류 영역의 수동 정답 마스크 또는 측색 기준
- 실제 코디 추천의 만족도

이번 30장은 실패를 찾아낸 **개발용 베이스라인**입니다. 여기에 맞춰 수정한 다음에는 별도로 고정한 새 사진으로 확인해야 합니다. 현재 사진만 반복해서 점수를 높인 결과를 일반 성능 향상으로 주장하지 않습니다.
