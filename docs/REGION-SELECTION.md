# 옷 영역 직접 선택

사진 업로드 → 영역 지정 → 선택 영역에서 색 추출 → 추천 흐름입니다.

- 마우스 또는 터치 드래그로 사각형을 새로 그립니다.
- 가로·세로 위치와 너비·높이 슬라이더로 조절할 수 있습니다. 키보드 방향키도 사용할 수 있습니다.
- 전체 선택, 선택 영역 미리보기, 분석 후 영역 재선택을 제공합니다.
- 좌표는 원본 이미지에 대한 비율로 보관합니다. 화면 크기와 관계없이 같은 영역을 분석합니다.
- 선택 영역 전체를 샘플링하며 추가 중앙 크롭을 하지 않습니다. 흰옷·검은옷이 배경으로 감점되지 않도록 선택 영역에서는 색 비중으로 정렬합니다.
- 원본 사진을 덮어쓰거나 서버에 전송하지 않습니다. 기존 브라우저 임시 저장 방식을 유지합니다.

## 검증 (2026-09-12)

- 단위 테스트 14개 및 프로덕션 빌드 통과.
- 영역 경계, 최소 크기, 역방향 드래그, 잘못된 좌표 검사.
- 브라우저 Canvas에서 좌우 빨강/파랑 합성 이미지의 각 절반을 선택해 각각 `#FF0000`, `#0000FF`가 추출됨을 확인.
- 실제 상품사진 21379에서 바지 일부를 드래그로 선택하고 분석, 영역 재선택 및 슬라이더 조절 확인.
- 이 사례의 기존 1순위는 흰 배경 `#FDFCFC`였고, 바지 일부를 선택한 결과는 `#323234`였습니다. 선택 부위가 다르므로 전체 정확도 향상 수치로 해석하지 않습니다.

## 남은 한계

사각형 선택이며 자동 의류 분할은 아닙니다. 선택 영역 안에 배경이 많이 들어오면 영향을 받습니다. 색 이름 매핑 문제는 별도이며 이번 변경에서 수정하지 않았습니다. 실제 휴대전화 터치 및 다양한 조명 사진의 추가 검증이 필요합니다.
