# 첫 바이브코딩에서 개선한 것들

## 사용자 경험

- 팔레트 중심 첫 화면과 사진 없는 체험 버튼
- JPG/PNG/WebP 및 3MB 크기 제한, 읽기·임시 저장 실패 안내
- 키보드 포커스와 모션 감소 설정 지원
- 추천 점수가 정확도나 만족 확률이 아님을 명시

## 단색 사진 오류

기존 K-means 초기화는 실제 색이 다섯 개보다 적으면 중심 개수를 덜 만들 수 있었습니다. 이후 반복은 요청한 다섯 개를 모두 참조해 존재하지 않는 중심에서 오류가 발생했습니다.

실제 생성된 중심만 순회하도록 변경했습니다. 초기 중심을 결정적으로 선택하여 동일한 픽셀 입력에서 결과가 재현되도록 했습니다. 빈 입력, 단색, 두 색, 재현성과 픽셀 개수 보존을 테스트합니다. 이미지 객체 URL도 로드 완료·실패 시 해제합니다.

## 검증

`npm ci` → `npm test` → `npm run build`

테스트 10개는 색 추출 경계 사례와 등록된 모든 색 × 6개 모드의 추천 개수(1–5), 중복, 본인 색 제외, 점수 범위, 같은 계열 최대 2개를 확인합니다. 이는 추천 규칙의 일관성 검사이며 패션 만족도 검증은 아닙니다. GitHub Actions에서도 테스트와 빌드를 실행합니다.

## 남은 과제

- 실제 옷 사진의 조명·배경별 평가 데이터셋
- 사용자가 옷 영역을 직접 지정하는 크롭 기능
- 저장소 사용이 제한된 환경에서 즐겨찾기·기록 처리 개선

AI 도구를 활용한 구현과 개선입니다. 테스트 개수가 실제 이용자 만족도를 대신하지는 않습니다.
